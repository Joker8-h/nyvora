# ¿Qué es Nexora?

Nexora es un **Business Operating System AI-First** diseñado para empresas que necesitan una plataforma modular de gestión empresarial potenciada por inteligencia artificial.

## Componentes Principales

### Nova - Asistente IA
Nova es el asistente inteligente de Nexora que puede:
- Crear y buscar clientes en el CRM
- Generar facturas y cotizaciones
- Buscar productos en inventario
- Generar reportes de ventas e inventario
- Y mucho más

### Módulos
- **CRM**: Gestión de clientes y contactos
- **Ventas**: Cotizaciones, facturas, pagos
- **Inventario**: Productos, stock, almacenes
- **Finanzas**: Cuentas por pagar/cobrar, reportes
- **RRHH**: Empleados, departamentos
- **Automatizaciones**: Nexora Flow
- **Marketplace**: Nexora Marketplace
