# Architecture Decision Records (ADR)

Los ADR documentan las decisiones arquitectónicas importantes del proyecto.

## Formato

Cada ADR sigue el formato:
1. **Título**: Nombre corto de la decisión
2. **Estado**: Propuesto / Aceptado / Obsoleto
3. **Contexto**: Situación actual
4. **Decisión**: Qué se decidió
5. **Consecuencias**: Impacto de la decisión
